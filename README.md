# Kod-Asistan v0.1
**Proje Yazarı:** Kerem Yaşar
## Projenin Amacı
Kullanıcılara hesaplama, selamlama ve günlük işlemlerde yardımcı olacak bir dijital asistan tasarlamaktır.
1. Başla
2. Kullanıcıdan bir değer al
3. Değeri kritik eşik ile karşılaştır
4. Değer eşikten büyük veya eşitse birinci işlemi yap
5. Değer eşikten küçükse alternatif işlemi yap
6. Sonucu ekrana yazdır
7. Bitir
kaynakça
9. sınıf ders kitabı.
